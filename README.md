# CH32V203F8U6 战术下挂枪灯 (Weapon Mounted Light - WML) 方案设计

本项目为一款超紧凑、极低待机功耗、免专用下载器的战术下挂枪灯主控系统。主控采用南京沁恒 (WCH) 官方 32 位 RISC-V 微控制器 **CH32V203F8U6 (QFN20 3×3mm 封装，Datasheet V3.0 权威校准版)**。

## 1. 官方权威物理引脚分配表 (QFN20 3×3mm 封装核准)

> [!CAUTION]
> **重要硬件排坑核对（严禁按普通 20-Pin 芯片惯性布局）：**
> 1. **主电源 VDD 位于 Pin 19**（并非 Pin 11）。
> 2. **主地线 GND (VSS) 是芯片底部的中心裸露焊盘 (EPad / Pin 0)**，PCB 必须设计中心大面积散热接地焊盘并打过孔！
> 3. **QFN20 内部默认 BOOT0=GND**，无外部独立 BOOT0 物理引脚。固件支持**通过关机长按按键 8 秒软件平滑跳转内置 USB Bootloader**，免拆机免跳线免抠电池刷机！
> 4. **指示灯采用单个 GPIO (PA4) 驱动 XL-1615RGBC-RF 智能全彩 RGB**，Pin 6 (PA5) 释放为备用引脚。
> 5. **PA6 物理引脚位于 Pin 20**（Pin 7 物理引脚为 PA7）。
> 6. **无需且无法外置晶振**：QFN20 (3×3mm) 封装未引出 PD0(OSC_IN) 与 PD1(OSC_OUT) 引脚，系统完全依托内置出厂校准的高精度 8MHz HSI RC 振荡器（片内 PLL 倍频至 72MHz），全速 USB 支持免晶振时钟自动校准，省去外部晶振与两颗负载电容，杜绝枪用高过载震动下石英晶体震裂停振风险。

## 2. 真实电路拓扑原理图 (Schematic Topologies)

### 2.1 MCU 最小系统与 Type-C 原生 USB 接口电路

```text
                               +3.0V (VDD)
                                 │
                                ┌┴┐
                           SW1  │ │ 主按键 (唤醒/切档/长按关机/8s进入烧录)
                                 \
                                ┌┬┐
                                 │
                                 ├────────────────────────────► Pin 1 (PA0, WKUP)
                                 │
                                ┌┴┐
                                │ │ R6: 100kΩ ±1% (弱下拉)
                                └┬┘
                                 │
                                GND
 
             Type-C 接口                                 CH32V203F8U6 (QFN20)
       ┌───────────────────┐                         ┌─────────────────────────┐
       │ D- (A7/B7)        ├───────[ 22Ω R4 ]────────┤ Pin 17 (PA11 / USB_DM)  │
       │ D+ (A6/B6)        ├───────[ 22Ω R3 ]────────┤ Pin 16 (PA12 / USB_DP)  │
       │ CC1 (A5)          ├───────[ 5.1k R1 ]───GND │                         │
       │ CC2 (B5)          ├───────[ 5.1k R2 ]───GND │ Pin 19 (VDD) ───────────┼── +3.0V
       │ VBUS (A4/B4/A9/B9)├──► 5V 充电输入          │ Pin 0  (EPad/GND) ──────┴── GND (底部焊盘)
       └───────────────────┘                         └─────────────────────────┘
```

> **USB 免仿真器固件升级说明**：
> 因 QFN20 内部硬件写死 `BOOT0=GND`，无外部 BOOT0 引脚，且电池持续在线供电，本固件利用 PA0 实现了纯软件平滑进入 ISP 烧录模式：
> 1. **关机状态下按住 8 秒进入烧录**：平时枪灯灭灯关机（Standby 待机模式）时，用 Type-C 线连接电脑，**直接按住主按键 SW1 (PA0) 保持 8 秒不松手**；RGB 指示灯亮金黄色确认，MCU 自动清空外设与中断并平滑跳转至内置 ROM Bootloader，电脑立即识别为 USB ISP 设备，使用官方 **WCHISPTool** 即可直接刷机！全程无需抠电池，亦无需拆卸外壳。
> 2. **反之短按正常开机**：关机时单击或短按（< 8秒）松手，主灯立即 100% 满功率点亮进入正常战术照明与切档控制。
> 3. **WCH-LinkE 单线烧录**：Pin 16 (PA12) 与 Pin 17 (PA11) 在复位时可作为 SWDIO / SWCLK 单线调试烧录口。

### 2.2 电池超低漏电电压检测电路 (ADC)

```text
       BAT+ (3.0V ~ 4.2V 锂电池)
         │
        ┌┴┐
        │ │ R8: 470kΩ ±1% (大阻抗抑制漏电)
        └┬┘
         ├───────────────────────┬─────────────────────────────► Pin 2 (PA1, ADC_IN1)
        ┌┴┐                      │
        │ │ R9: 470kΩ ±1%       ┌┴┐
        └┬┘                     ─── C9: 100nF (滤波稳定输入)
         │                      ───
        GND                      │
                                GND
```
* **静态待机漏电**：$I = 4.2\text{V} / 940\text{k}\Omega \approx 4.46\text{µA}$。
* **分压比**：1:1，满电 4.2V $\rightarrow$ Pin 2 采样 2.1V。

* **通道 1 (PWM1)**：驱动 **3535 封装大功率白光 LED**，目标照度 **500LX ~ 1000LX**。检流电阻 $R_{s1}$ 选用 **$0.56\Omega$ ($560\text{m}\Omega$, 对应 357mA / 500~750LX)** 或 **$0.40\Omega$ ($400\text{m}\Omega$, 对应 500mA / 800~1000LX)**，**0805 封装**。
* **通道 2 (PWM2)**：驱动 **650nm 3mW 红光激光二极管 (Laser Diode)**，作为战术瞄准指示。检流电阻 $R_{s2}$ 选用 **$10.0\Omega \pm 1\%$ (对应 20.0mA 恒流直驱)**，**0603 封装**；激光管并联 $1\mu\text{F}$ 滤波电容 C8 吸收开关纹波，并反向并联肖特基管 D2 (BAT54WS) 防止反向电压与静电冲击击穿激光管。

## 4. 软件逻辑与 RGB 指示灯交互规范

### 4.1 按键交互操作手册

1. **单击模式循环**：
   * 第 1 档：**主灯 100%** (PWM1 100%, PWM2 0%)：3535 WLED 满功率照明 (500LX~1000LX)。
   * 第 2 档：**主灯 25%** (PWM1 25%, PWM2 0%)：3535 WLED 节能低功耗照明。
   * 第 3 档：**主灯+副灯 同时亮** (PWM1 100% + PWM2 100%)：**3535 主照明 + 650nm 3mW 红光瞄准激光同时常亮**，实现战术照射与激光瞄准协同。
   * 第 4 档：**同时关闭** (全灭关灯，指示灯全灭，启动 10 秒倒计时)。
   * 再次单击循环回到第 1 档。
2. **双击**：进入 **10Hz 战术爆闪模式**，单击退出回到关灯状态。
3. **三连击**：进入 **国际标准 SOS 救援模式 (· · · — — — · · ·)**，单击退出回到关灯状态。
4. **长按 (> 1.2s)**：**任何模式下长按全部关闭**，指示灯熄灭，启动 10 秒倒计时：
   * 10 秒内单击：重新开机进入第 1 档。
   * **10 秒无操作**：自动进入 **Standby 待机低功耗休眠（~10µA）**。
5. **关机按住 8 秒进入烧录**：平时关机灭灯（Standby 待机模式）时按住 SW1 (PA0) 持续 8 秒不放，RGB 指示灯亮金黄色确认，直接平滑跳转进入内置 ROM Bootloader 开启 USB ISP 烧录；反之短按松手则立即点亮进入第 1 档正常照明。冷装电池未按键默认直接进入低功耗休眠。
6. **备用按键 (SW2 / PA6 / Pin 20)**：战术点动，按住强行 100% 满功率极亮，松手恢复原状态。

### 4.3 智能低压自适应续航与防跳水阶梯降档机制 (LVP)

针对单节锂电池 (3.0V~4.2V) 供电并在放电末期可能跌穿 3.3V LDO 稳压门限的特性，固件内建高可靠性电源管理策略：

1. **芯片内部 1.20V Vrefint 带隙基准绝对校准**：
   - 当电池电压低于 3.4V 时，LDO 稳压输出会跟随电池电压下跌 ($V_{DD} \approx V_{bat} - 0.05\text{V}$)。
   - 固件通过周期同时采样外部电池分压通道与内部不受 $V_{DD}$ 波动影响的 $1.20\text{V}$ 内部参考基准通道，联立消去浮动的真实 $V_{DD}$：
     $$V_{bat} (\text{mV}) = \frac{2400 \times ADC_{bat}}{ADC_{vref}}$$
   - 实现了在 $2.5\text{V} \sim 4.2\text{V}$ 全电压跨度内测量精度高达 $\pm 1\%$，彻底消除传统 ADC 因基准跌落导致的测量虚高误判。

2. **自适应 4 级放电阶梯降档算法**：
   - **满血放电档 ($\ge 3.4\text{V}$)**：允许 100% 满功率自由放电与高频爆闪。
   - **节能限流档 ($3.1\text{V} \le V_{bat} < 3.4\text{V}$)**：自动将最高输出功率限制在 **25%**（电流由 1.5A 骤降至 200mA）。避免因电池内阻激增导致放电突发大电流引发电压瞬间断崖跳水（黑屏关机），平滑延长使用时间 30~60 分钟。
   - **保命微光档 ($2.95\text{V} \le V_{bat} < 3.1\text{V}$)**：强制切换为主灯 **5% 月光档**（副灯关闭），整机运行电流仅 ~20mA，光通量适于脚下路面应急照亮，**为用户额外榨出 1~2 小时的极限保命续航**！
   - **截止断电保护 ($V_{bat} < 2.95\text{V}$)**：红灯快速闪烁警示后立即自动熄灭并切入 **Standby 极低功耗待机模式 (<10µA)**，完全隔离主回路，保护锂电芯不被过放损毁。

## 5. 硬件选型深度优化与延长续航设计考量

针对单节锂电池 3.0V~4.2V 供电系统的续航与可靠性要求，本项目在元器件选型上进行了 4 项关键优化：

### 5.1 LDO 稳压器：从 3.3V 升级为 3.0V 超低压差规格 (ME6211C30 / SGM2036-3.0)
* **传统 3.3V LDO 痛点**：单节锂电在 3.0V~3.4V 之间占据了约 15%~25% 的有效可用容量。若使用 3.3V LDO，电池电压降至 3.4V 时 LDO 即失去稳压能力，系统提早进入未稳压直通状态。
* **改用 3.0V 超低压差 LDO 优势**：
  1. **全程稳压**：由于 ME6211 的压降在轻载（<30mA）下仅有约 40mV~60mV，**电池从 4.2V 一路放电至 3.05V 的整个放电周期内，LDO 全程处于高精度真实稳压区**！
  2. **MCU 完美兼容**：CH32V203 官方标称供电范围为 2.4V~3.6V，在 3.0V 供电下无论是 72MHz 高频运算、全速 USB 还是 ADC 均工作在极佳电气状态；
  3. **降低系统静态功耗**：根据 $P = U \times I$，供电由 3.3V 降为 3.0V，MCU 内核与数字外设功耗自然下降约 10%。

#### 5.2 LED 恒流驱动 IC：选用超小微型同步降压 TI TPS92201DRVR (WSON-6 2×2mm, 立创 C22427296)
* **WSON-6 超微型封装 (2×2mm)**：相比常规 SOT-23-6 封装体积直接缩减 **52%**，面积仅 4mm²，自带底部裸露大面积散热焊盘（Thermal Pad），极度契合战术枪灯狭小 PCB 空间；
* **单节锂电量身定制 (2.5V ~ 5.5V)**：完全覆盖单锂电从 4.2V 满电到 2.8V 极低电的全放电区间，放电全程绝不因低压而停振；
* **内置同步整流 MOS（免外部肖特基二极管）**：集成上下管功率 MOSFET，转换效率高达 **95%**，省去外部续流二极管，外围仅需 1 个小型电感（2016/2520）与 1 个采样电阻；
* **100% 占空比直通 (LDO Mode)**：当电池放电后期电压（如 3.1V）接近白光 LED 的正向导通压降 $V_F$ 时，内部上管 MOS **100% 常开直通**，消除高频开关损耗与二极管导通压降，杜绝黑屏跳水；
* **精确 20.00kHz 硬件高频 PWM 驱动**：MCU TIM2 输出精确 20kHz 超声调光信号直连 EN/PWM 引脚，实现 **1% ~ 100% 线性无频闪、零可听啸叫**调光；待机时 EN 拉低关断电流仅 **1µA**。

#### 5.2.1 PWM1: 3535 WLED 照度 (500LX ~ 1000LX) 与限流采样电阻阻值/封装选型
1. **照度目标与驱动电流匹配**：
   - 战术枪灯测试标准依据 ANSI/NEMA FL-1，1 米处中心照度达到 **500LX ~ 1000LX**（对应中心光强 500cd ~ 1000cd）。
   - 配合枪灯专用微型聚光透镜/反光杯（光强系数约 $3 \sim 6\text{ cd/lm}$），系统所需输出光通量约 **$100\text{ lm} \sim 250\text{ lm}$**。
   - 采用 3535 陶瓷基板封装大功率白光 LED（如 Cree XP-G3 / SST-20 / 国产 3535），正向导通压降 $V_F \approx 2.8\text{V} \sim 3.2\text{V}$，发光效率约 130~150 lm/W，匹配工作电流为 **$350\text{mA} \sim 500\text{mA}$**。
2. **限流检流电阻 $R_{s1}$ 阻值理论计算 ($V_{FB} = 200\text{mV} = 0.20\text{V}$)**：
   $$I_{LED} = \frac{V_{FB}}{R_{s1}} = \frac{0.20\text{V}}{R_{s1}}$$
   - **500LX 档（标准聚光照路）**：目标电流 $I = 350\text{mA} = 0.35\text{A}$
     $$R_{s1} = \frac{0.20\text{V}}{0.35\text{A}} \approx 0.571\Omega \implies \text{选用标准 E24 阻值 } \mathbf{0.56\Omega} \quad (560\text{m}\Omega, 1\%)$$
     实际电流：$I = \frac{0.20}{0.56} \approx 357\text{mA}$。电阻功耗：$P = I^2 R = (0.357)^2 \times 0.56 \approx 71\text{mW}$。
   - **1000LX 档（强光高亮聚光）**：目标电流 $I = 500\text{mA} = 0.50\text{A}$
     $$R_{s1} = \frac{0.20\text{V}}{0.50\text{A}} = \mathbf{0.40\Omega} \quad (400\text{m}\Omega, 1\%) \quad \text{或选用 E24 标称 } 0.39\Omega / 0.47\Omega$$
     实际电流：$I = 500\text{mA}$。电阻功耗：$P = 0.20\text{V} \times 0.50\text{A} = 100\text{mW}$。
3. **封装与耐功率选型**：
   - 阻值功耗在 71mW ~ 100mW 之间，推荐选用 **0805 封装**（额定功率一般为 1/8W ~ 1/4W 即 0.125W ~ 0.25W），金属合金或精密厚膜电阻。额定功率具备 **2.5 倍** 以上充足安全裕量，发热极小，且具备低温漂特性（$\le \pm 100\text{ppm/}^\circ\text{C}$）。

#### 5.2.2 PWM2: 650nm 3mW 红光激光二极管 (LD) 驱动与限流电阻选型及抗浪涌保护
1. **激光管工作特性与恒流需求**：
   - 650nm 红光激光二极管作为战术枪灯的瞄准辅助准星，光输出功率标准设定在 **~3mW**（Class 3R 激光安全合规，室内及夜间 10~25 米内瞄准红点清晰敏锐）。
   - 典型 650nm 3mW 激光二极管（如 TO-18 / Φ5.6mm 工业 LD 或 6mm 激光铜头模组）正向压降 $V_F \approx 2.1\text{V} \sim 2.4\text{V}$，起振阈值电流 $I_{th} \approx 10\text{mA} \sim 15\text{mA}$，输出 3mW 时的标称工作电流为 **$18\text{mA} \sim 22\text{mA}$**（标准取 **$20.0\text{mA}$**）。
2. **限流检流电阻 $R_{s2}$ 阻值理论计算**：
   $$R_{s2} = \frac{V_{FB}}{I_{laser}} = \frac{0.20\text{V}}{0.020\text{A}} = \mathbf{10.0\Omega} \quad (\pm 1\%)$$
   - 选用标准阻值 **$10.0\Omega \pm 1\%$** 时，输出电流恒定为 **$20.0\text{mA}$**，驱动激光二极管平稳输出 **$3.0\text{mW}$** 鲜艳红色准星；
   - 若需微调输出光功率：选用 $12.0\Omega \implies I = 16.7\text{mA}$ (约 2.2mW)；选用 $9.1\Omega \implies I = 22.0\text{mA}$ (约 3.5mW)。
3. **功耗与封装选型**：
   $$P = I^2 R = (0.02\text{A})^2 \times 10\Omega = 0.004\text{W} = \mathbf{4\text{mW}}$$
   - 4mW 功耗极微，选用 **0603 封装**（额定 1/10W = 100mW，安全裕量达 **25 倍**）或 **0402 封装**（额定 1/16W = 62.5mW，安全裕量达 **15 倍**），1% 精度贴片电阻。
4. **激光二极管专用保护电路设计 (抗浪涌与防烧管)**：
   - **输出并联吸收电容 (C8: 1µF 16V X7R 0603)**：激光二极管对瞬态浪涌电流极其敏感，C8 能有效平滑 TPS92201 的高频开关纹波，并吸收上电瞬间的任何过冲尖峰。
   - **反向保护二极管 (D2: BAT54WS 肖特基, SOD-323 / 0603)**：反向并联在激光管两端，快速吸收外来感应尖峰与反向 ESD 静电，彻底杜绝激光二极管因反向过压而击穿报废。

### 5.3 指示灯：单线智能全彩 RGB (XL-1615RGBC-RF)
* **释放关键 GPIO**：仅占 1 个引脚即可实现 1600 万色丰富指示，释放 Pin 6 (PA5)；
* **内部恒流**：灯珠内嵌驱动 IC，外部不再需要串联分立限流电阻，杜绝了电阻分压对低压下指示灯亮度的影响；
* **3.0V 宽压运行**：该灯珠内置芯片在 3.0V 稳压系统下完全正常接收 800kHz 归零码信号，红光与绿光/蓝光均清晰稳定。

### 5.4 电池分压采样电阻：470kΩ + 470kΩ 超大阻抗
* **抑制待机漏电**：传统分压网络若使用 10kΩ + 10kΩ，在电池端会形成常闭回路产生 $4.2\text{V} / 20\text{k}\Omega = 210\text{µA}$ 的恒定漏电，手电关机数月就会把电池放空；
* **微安级设计**：改用 470kΩ + 470kΩ 后，静态漏电流仅 $4.2\text{V} / 940\text{k}\Omega \approx 4.46\text{µA}$，配合 C9 (100nF) 吸收采样瞬态电荷，兼顾了超高采样精度与极致长效待机。
